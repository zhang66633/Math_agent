# 评价类建模规范

## 一、指标体系先立住

- 每条指标必须**可观测、可量化、与目标相关**，且彼此尽量不重复（高度相关的指标要合并或说明保留理由）；
- 给出指标的正负向（越大越好 / 越小越好）与单位；
- 数据缺失要说明处理方式（剔除 / 插补 / 降级为定性指标），不要静默补零。

## 二、赋权方法的选择

| 情形 | 方法 | 必须附带的检验 |
|------|------|----------------|
| 专家/经验可给出相对重要性 | 层次分析法（AHP） | **一致性检验 CR < 0.1**，否则返回重调判断矩阵 |
| 数据充分、希望客观 | 熵权法 | 说明数据离散程度对权重的影响 |
| 既要主观经验又要数据支撑 | AHP + 熵权组合（乘法或线性加权） | 说明组合系数怎么来的 |
| 指标只有定性等级 | 模糊综合评价 | 隶属度函数或评语集要显式给出 |

## 三、排序方法的选择

- 一般多指标排序 → **TOPSIS**（构造加权规范化矩阵 → 正负理想解 → 相对贴近度），必须写明归一化方式；
- 投入产出效率比较 → **DEA**（说明 DMU 选择与规模报酬假设）；
- 等级判定 → 模糊综合评价，给出隶属度矩阵与最大隶属度原则。

## 四、必须自查的坑

- **不做指标正向化与归一化**就直接加权求和（量纲不同的指标相加无意义）；
- AHP 判断矩阵不检验一致性，或检验不通过仍继续使用；
- 权重全部来自主观赋值却不说明依据，或全部客观赋权却解释不出经济含义；
- 只给出一个最终排名，不说明**权重变化后排名是否稳定**（这一项交由验证环节，但建模阶段要留下权重参数）。
