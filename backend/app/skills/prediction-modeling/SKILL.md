# 预测类建模规范

## 一、先看数据特征，再选方法

| 数据特征 | 推荐方法 | 说明 |
|----------|----------|------|
| 样本极少（< 15 个点）、近似指数增长 | 灰色预测 GM(1,1) | 必须做**后验差比检验**（C 值）与残差检验 |
| 有明显线性趋势、样本量中等 | 多元线性回归 / ARIMA | 回归要报告系数显著性与 R²；ARIMA 要给出 (p,d,q) 定阶依据（ACF/PACF 或 AIC） |
| 有季节性/周期性 | 季节性分解 + SARIMA / 指数平滑 | 显式给出周期长度 |
| 多变量、非线性、样本充足 | 随机森林 / 梯度提升 / 神经网络 | 必须划分训练/验证集并报告两边的误差 |
| 变量之间有明确机理关系 | 机理模型 + 参数拟合 | 优先于纯数据驱动，并说明参数辨识方法 |

## 二、预测任务的三条硬要求

1. **划分数据**：不得用全部数据训练又用同一批数据报告精度；至少留出最后一段时间做样本外检验；
2. **报告误差指标**：MAE、RMSE 之外，尽量给出 **MAPE**（百分比误差更便于解释）；说明指标选择理由；
3. **残差检验**：残差应近似零均值、无显著自相关；若残差有结构（趋势/周期残留），说明模型未捕捉到的成分。

## 三、必须自查的坑

- 样本量不足却上神经网络（参数远多于样本，必然过拟合，且无法解释）；
- 时间序列随机划分训练/测试集（**必须按时间顺序切分**，否则数据泄漏，精度虚高）；
- 只报一个最优模型，不比较基线（至少给一个朴素基线：如"用上一期值预测下一期"）；
- 给出点预测却不给区间或误差范围，让使用者误以为精确。
