# 优化类建模规范

## 一、三件套必须齐全

任何优化模型都必须显式写出，缺一项即为不合格：

1. **决策变量**：符号、含义、单位、类型（连续 / 整数 / 0-1）；
2. **目标函数**：最大化还是最小化，量纲是什么；
3. **约束条件**：每一条都写成数学式，并注明来源（题目给定 / 现实假设）。

## 二、模型选择的判定顺序

按以下顺序判断，命中即停，不要跳步：

1. 目标与约束**都是线性**、变量连续 → 线性规划（LP）；
2. 变量要求整数或 0-1（选址、指派、排班）→ 整数/混合整数规划（IP/MIP）；
3. 目标或约束含**非线性**，且能写成凸形式 → 凸优化（用 `cvxpy` 求解，并说明凸性依据）；
4. 多个互相冲突的目标 → 先说明是加权求和、ε-约束还是 Pareto 前沿（NSGA-II）；
5. 解空间组合爆炸、无法精确求解 → 启发式（遗传算法 / 模拟退火 / 粒子群 / 蚁群），**必须给出收敛曲线**；
6. 决策分阶段且后一阶段依赖前一阶段 → 动态规划，明确状态、阶段与转移方程；
7. 图与网络结构（最短路、最大流、最小生成树、匹配）→ 直接用图算法建模，不要硬套线性规划。

## 三、求解器与实现约定

- 凸问题用 `cvxpy`；有约束的非线性用 `scipy.optimize.minimize`（按需选 SLSQP / trust-constr）；
- 写出模型后**先小规模验证再放大**：用 3～5 个变量的人工算例核对结果，确认无误再跑全量；
- 求解状态必须检查（`status == optimal` / `success`），不可行或无界必须报告原因而不是输出空结果。

## 四、必须自查的坑

- 把**非凸**问题当凸问题解（解是局部最优却不说明）；
- 漏写非负约束、整数约束或上界，导致解在现实中不可行；
- 目标函数各项量纲不一致（如把"成本（元）"与"时间（小时）"直接相加）——必须先归一化或加权说明；
- 只给一个最优解、不做**参数变化后的稳定性**说明（这一项交由验证环节完成，但建模阶段要预留可调参数）。
