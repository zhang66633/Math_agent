## 3. 核心学习机制

### 3.1 知识图谱技能树

知识点不是线性列表，而是**有向图**。从现有方法卡片中提取前置依赖和横向关联：

```
评价类方法（局部）
                              ┌──────────┐
                              │ 评价类方法 │
                              └────┬─────┘
                                   │
              ┌────────────────────┼────────────────────┐
              │                    │                    │
        ┌─────▼─────┐       ┌─────▼─────┐       ┌─────▼─────┐
        │    AHP    │       │  TOPSIS   │       │  熵权法    │
        └─────┬─────┘       └─────┬─────┘       └─────┬─────┘
              │                   │                    │
    ┌─────────┼─────────┐        ...                  ...
    │         │         │
┌───▼──┐ ┌───▼───┐ ┌───▼──┐
│特征值 │ │判断矩阵│ │一致性│
│计算   │ │构造    │ │检验  │
└───────┘ └───────┘ └──────┘
```

- **前置依赖边**: "一致性检验" 依赖 "特征值计算"
- **横向关联边**: "AHP" 和 "TOPSIS" 同属评价类，做方法对比
- **难度递进边**: "AHP基础" → "模糊AHP"

### 3.2 艾宾浩斯遗忘曲线复习

| 学习后时间 | 记忆保留率 | 系统动作                |
| ---------- | ---------- | ----------------------- |
| 刚学完     | 100%       | —                      |
| 1天后      | ~70%       | 推送1道回顾题           |
| 3天后      | ~50%       | 推送3道综合复习题       |
| 7天后      | ~30%       | 提醒「该重新学习xxx了」 |
| 遗忘(<30%) | —         | 自动标记为「需复习」    |

午夜定时任务重算所有已学知识点的保留率，<80% 自动入复习队列。

### 3.3 贝叶斯掌握度建模

不记录「学过/没学过」，而是概率化评估：

```
传统: 层次分析法: 已学 ✅
本系统: 层次分析法: P(掌握)=0.72
        ├── 构造判断矩阵: 0.85 (强)
        ├── 特征值计算:   0.70 (一般)
        └── 一致性检验:   0.45 (弱！需要加强)
```

P(掌握) = 先验(0.2) + 练习正确×0.15 - 练习错误×0.10 - 每天衰减×0.95

### 3.4 动态难度调整 (DDA)

根据最近表现实时浮动：

- 最近3题全对 → 难度 +0.3
- 最近3题对2题 → 难度 +0.1
- 最近3题对1题 → 难度 -0.1
- 最近3题全错 → 难度 -0.3 + 触发补救学习

### 3.5 联网资源推荐

学生表示不懂时，智能体不是反复用自己的话解释，而是：

```
学生: "我还是不太理解特征值和特征向量"
🧩 建模师: "这个概念确实比较抽象。
  推荐你看看 B站 @宋浩老师 的线性代数第 5.1 节，
  他用几何方式解释特征向量，非常直观。
  另外《数学建模算法与应用》第 2.3 节也有很好的解释。
  需要我把视频链接贴出来吗？"
```

搜索渠道：B站 / 教材 / GitHub / StackOverflow / 知网。复用项目已有的 `web_search_tools.py`，增加 B站搜索能力。

## 4. 三人角色学习体系

### 4.1 建模手技能树

```
建模手
├── §1 数学基础 (线性代数/概率统计/优化理论/微分方程)
├── §2 方法库
│   ├── 优化类: LP → IP → DP → GA/SA/PSO
│   ├── 预测类: 回归 → ARIMA → 灰色预测
│   ├── 评价类: AHP → TOPSIS → 熵权法 → 模糊综合评价
│   ├── 统计类: MLE → 贝叶斯 → 蒙特卡洛
│   ├── 图论类: 最短路 → 网络流 → MST
│   └── 综合类: 排队论/博弈论/元胞自动机
├── §3 问题分析 (问题重述/假设建立/变量识别/方案比较)
└── §4 模型创新 (组合模型/灵敏度分析/模型改进)
```

### 4.2 编程手技能树

```
编程手
├── §1 Python基础 (NumPy/SciPy/Pandas/规范)
├── §2 模型实现 (scipy.optimize/cvxpy/sklearn/SymPy/networkx)
├── §3 数据能力 (清洗/预处理/特征工程/可视化)
├── §4 算法设计 (复杂度/启发式调参/性能优化)
└── §5 工程规范 (注释文档/结果输出/版本控制)
```

### 4.3 论文手技能树

```
论文手
├── §1 学术写作 (论文结构/学术语言/逻辑叙事/格式规范)
├── §2 章节专项 (摘要/重述/假设/建模/分析/评价)
├── §3 图表可视化 (图表选择/三线表/图文配合)
├── §4 排版工具 (LaTeX/Word/公式)
└── §5 文献资料 (检索方法/引用规范)
```

## 5. 学习闭环

```
首次进入 → 🧭 导航员: 角色选择 + 水平自评
    │
    ▼
🧭 导航员: 生成学习路径 (基于知识图谱 + 角色)
    │
    ▼
🎯 学习工位: 智能体讲解知识点
    │
    ├── [✅ 我懂了] → 掌握度提升 → 解锁下一单元
    ├── [❓ 不太懂] → 智能体换方式讲解 or 推荐B站/教材
    └── [✏️ 做道题] → 跳转训练场
    │
    ▼
✏️ 训练场: 智能体出题 → 提交 → 智能体批改
    │
    ├── 正确 → 掌握度 +0.15
    └── 错误 → 掌握度 -0.10 + 补救学习推荐
    │
    ▼
📊 管家: 每日遗忘衰减计算 → 定期推送复习 → 成就解锁
    │
    ▼
🏆 (原/solution) 实战检验 → 赛后复盘
```

## 6. 数据模型

```yaml
UserProfile:
  user_id: string
  roles:
    - role: modeler|programmer|writer
      level: beginner|intermediate|advanced|competition
      is_primary: bool
  goal: { competition, target_date, weekly_hours }
  calibrated_skills:
    modeler: { overall: 0.35, skills: { linear_algebra: 0.6, ... } }
    programmer: { ... }
    writer: { ... }
```

### 6.2 学习路径

```yaml
LearningPath:
  path_id: string
  user_id: string
  role: modeler|programmer|writer
  phases:
    - name: string
      units:
        - unit_id: string
          title: string
          type: knowledge|practice|project
          difficulty: beginner|intermediate|advanced
          dependencies: [unit_id]
          status: pending|in_progress|completed
          mastery_score: 0.0-1.0
```

### 6.3 练习记录

```yaml
ExerciseRecord:
  record_id: string
  unit_id: string
  type: multiple_choice|short_answer|code|writing|modeling
  user_answer: string
  score: float
  feedback: { strengths, weaknesses, suggestions }
  created_at: datetime
```
