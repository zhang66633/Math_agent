# 论文写作规范

## 一、摘要（最后写，但读者最先看）

- 结构固定：**问题 → 方法 → 结果 → 结论**，一段话写完；
- **必须出现具体数字**：模型给出的关键数值结果（最优值、预测值、误差、排名第一的对象），不能只说"建立了模型并求得结果"；
- 不出现公式推导、不出现文献综述、不出现"本文将……"这类空承诺。

## 二、章节职责边界（不得越界）

| 章节 | 只写什么 | 不得出现 |
|------|----------|----------|
| 问题重述 | 用数学语言提炼已知量、未知量、目标 | 照抄题面原文 |
| 问题分析 | 关键特征、难点、建模思路的递进 | 假设清单、公式推导 |
| 模型假设与符号说明 | 4～6 条一句话假设 + 符号表 | 全文**只在此处**定义假设与符号 |
| 模型的建立与求解 | 建模思路、模型与算法、求解结果与图表 | 与前文重复的假设或符号定义 |
| 模型检验与灵敏度分析 | 正确性、灵敏度、稳健性、误差 | 新的模型设定 |
| 模型评价与改进 | 优点 2～3 条、不足与改进 2～3 条 | 空泛套话（"模型具有较好的推广性"） |
| 参考文献 | 3～5 条**真实存在**的经典文献 | 编造的文献 |
| 附录 | 全部代码原样收录，按模型分小节 | 省略或改写的代码 |

## 三、图表与公式

- 图表必须有编号与标题（图 1、表 1），并在正文中被引用（"如图 1 所示"）；
- 表格优先用三线表；数据表要给单位；
- 关键公式单独成行并编号，符号在同一篇论文里含义唯一；
- 引用求解结果中的图片时，使用材料里给出的图片链接，不要凭空描述图形。

## 四、必须自查的坑

- 摘要里没有数字结果（这是最容易被扣分的一项）；
- 假设或符号在多个章节重复定义、且前后不一致；
- 有图无引用、有表无单位、公式无编号；
- 附录代码缺斤少两（"此处省略"）；
- 结论超出模型实际能支撑的范围（例如用线性模型得出长期非线性结论却不加限定）。
