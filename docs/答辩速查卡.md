## 三、三大创新（每个讲完停一秒，再进下一个）

1. **流程即智能体，不是一个万能助手。**
   为什么：单 Agent 又审题又写代码又自检，角色互相污染、出错无法定位；拆成 7 个角色后，每个环节可验证、可回退。
2. **知识库是弹药库，不是装饰。**
   为什么：数学建模是知识密集型任务，没有检索增强的大模型会一本正经地编造不适用的模型。
3. **学习与实战同源。**
   为什么：61 个单元的长文就是知识库里方法卡的长文（同一份 YAML 数据、两个视图），训练场答错的知识点会直接影响学习工位推荐的下一个单元——学和用必须是同一套知识体系。

## 五、临场红线（老师原话：打理一下自己、语言洪亮规范）

- **形象**：纯色有领上衣或干净衬衫，头发别遮眼；不穿拖鞋、球鞋要干净；不用夸张饰品；手机静音反扣。
- **站位**：主讲站在屏幕侧前方 45°，绝不挡屏幕；三人横排，主讲居中，另外两位别插兜、别低头看手机。
- **声音**：比平时大一档，开口前吸一口气；用 **0.5 秒停顿**代替「呃 / 那个 / 然后」；最后一句一定要放慢、加重。
- **规范用语**：称呼「各位老师」；被提问先说「谢谢老师，这个问题是这样的」；不用网络词（炸裂 / 牛逼 / 绝了）；答完补一句「我说明白了吗」。
- **时间**：指定一人计时（手机秒表），到 5:30 用眼神提示主讲；宁可少讲一个亮点，绝不超时。
- **交接**：换人时用一句话承接——「刚才演示的是求解与验证，接下来由我说明检索部分。」不要沉默换人、不要抢话。
